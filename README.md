# yogatop
power monitoring for Lenovo Yoga C930 laptop

inspired by [ztop](https://github.com/geohot/ztop) to explore system power management

## specs

Lenovo Yoga C930
- i7-8550U (UHD 620 graphics)
- 16GB ram (DDR4-2400)
- PCIe (3.0 x 4) NVME SSD
- Wifi 6E & Bluetooth - AX210 card
- 1080p LCD touchscreen display
- 720p integrated camera
- 60 Wh battery
- 1 x USB 3.1 Gen 1 (always on)
- 2 x USB-C 3.1 Gen 2 / Thunderbolt 3
- 1 x headphone / microphone jack
- keyboard with backlight

**spec sheet battery life**

MobileMark 2014: 12hr
